Sidebar menu design updates:

- The active item has a bar in the brand colour. For sub-items the bar sits on the sub-menu line.
- An open folder that contains the current page shows its name in bold with no fill. A closed folder in that state takes the highlight itself.
- Section headers show their chevron only on hover, on focus, or while the section is collapsed.
- Links that open in a new tab show a small arrow.
- In the collapsed sidebar, the folder pop-out shows the folder name at the top.
