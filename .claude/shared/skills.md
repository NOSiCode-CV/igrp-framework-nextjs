# Skills to use

Reach for these skills whenever the task fits. Don't wait to be asked.

- **`/ponytail-*`**: `ponytail` for any coding task (the smallest change that fully solves it), `ponytail-review` to review a change, `ponytail-audit` to audit the whole repo, `ponytail-debt` to list deferred `shortcut:` comments, and `ponytail-help` / `ponytail-gain` for reference.
- **`/graphify`**: for questions about the codebase, its architecture or how files relate. When `graphify-out/` exists, query it first.
- **`/unslop`**: for prose (docs, CLAUDE.md, changelogs, changesets, commit and PR messages, code comments), to strip out AI writing patterns before it lands.
