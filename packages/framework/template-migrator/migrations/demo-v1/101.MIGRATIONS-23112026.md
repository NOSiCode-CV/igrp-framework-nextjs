# 101 — The migration guide describes the compact lock

## What changed

| File | Change |
| --- | --- |
| `docs/MIGRATION_GUIDE.md` | The `rollback` section is gone. A new "Undoing a migration" section says to revert the migration's commit with git. "The lock file" describes the compact format. |

## Why

`@igrp/template-migrator` no longer stores file contents in `.igrp-migrations-lock.json`. The lock keeps each migration's id and hashes, grouped by CLI version line. Lock files with undo content grew past 1 MiB, Biome's default file size limit. Without that content, the CLI cannot roll back a migration, so the `rollback` command is removed.

## Behaviour changes to check

- `igrp-migrate rollback` no longer exists. To undo a migration, revert its commit with git.
- The next `apply` rewrites `.igrp-migrations-lock.json` in the compact format. Commit the result.
- A CLI older than this release cannot read the compact lock. Use `@igrp/template-migrator@latest`.

## After migrating

Commit `.igrp-migrations-lock.json`.
