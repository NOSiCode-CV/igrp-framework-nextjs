# 109 — Document that the menu push resets the menu roles on every pod start

## What changed

| File | Change |
| --- | --- |
| `.env.example` | Warning on `IGRP_SYNC_ON_CODE_MENU_ROLES`. |
| `docs/ENVIRONMENT.md` | The same warning in the variable table. |

## Why

Audit 2026-11-25, item 16. With `IGRP_SYNC_ON_CODE_MENUS=true`, the menu push runs once per process. With `IGRP_SYNC_ON_CODE_MENU_ROLES` unset or `true`, every new pod (a deploy, a scale-up, a restart) resets the menu roles to the code's and undoes role edits made in Access Management. The default stays `true`: changing it could leave new menus without roles.

## Behaviour changes to check

None. Documentation only. If your app pushes menus from code and AM administrators edit menu roles, set `IGRP_SYNC_ON_CODE_MENU_ROLES=false` in your `.env`.
