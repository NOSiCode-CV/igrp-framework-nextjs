No template files change. Each package's CHANGELOG lists its fixes; the ones an app can notice are below.

## Behaviour changes to check

- **Peer dependencies.** `@igrp/framework-next` takes `next-intl` (`^4.16.1`) as a peer, and `@igrp/framework-next-ui` takes `lucide-react` as a peer. Keep `next-intl` in your `package.json` at 4.16.1 or later.
- **Auth bypass.** `isIgrpAuthBypass()` follows the `withIGRPAuth` instance. An app with `provider: 'igrp-auth'` and a leftover `AUTH_PROVIDER=none` no longer bypasses auth in server actions and permission checks.
- **Middleware matcher.** The default matcher no longer skips `/apps`. A route under `/apps` inside the app now gets the auth check and the security headers.
- **Removed `withAuth`.** `@igrp/framework-next-auth/middleware` no longer re-exports NextAuth's `withAuth`. Use `withIGRPAuth` or `igrpMiddlewareDecision`.
- **Deprecated helpers.** `getServerSessionStrict`, `sanitizeString`, `sanitizePath`, `getLoginPath`, `hasAccessToken`, `useSafeSession`, `igrpBuildQueryString`, `IGRPGlobalLoading` and the `@igrp/framework-next/client` entry are deprecated. A later release removes them.
- **`NEXTAUTH_URL` warning.** `withIGRPAuth` warns once at startup when the path of `NEXTAUTH_URL` is not `NEXT_PUBLIC_BASE_PATH` + `/api/auth`.
- **Error codes.** An `IgrpError` with a code sets `digest` to `<id>|<code>`, so the client keeps the code in production.
- **Sidebar user menu.** `showProfile` and `showSettings` (default `true`) hide the Profile and Settings entries.
