# 46 — Mock user typed with `@igrp/framework-next-types`

## What changed

| File | Change |
| --- | --- |
| `src/temp/users/user.ts` | `IGRP_MOCK_USER` is now typed `IGRPUserArgs` from `@igrp/framework-next-types` instead of `IGRPUserDTO` / `Status` from `@igrp/platform-access-management-client-ts`. The `as Status` cast is gone |

## Why

The mock user only reaches the header and sidebar data (`getHeaderData` /
`getSidebarData` in `src/igrp.template.config.ts`), whose `user` field is
`IGRPUserArgs`, the framework's own user shape. Typing it as the AM client's DTO
compiled only because the DTO is a superset.

`IGRPUserArgs.status` is the literal union `IGRPStatus`
(`'ACTIVE' | 'INACTIVE' | 'DELETED'`), not the client's `declare enum`, so the
plain string needs no cast. The shape is contract-checked against the AM client
by `@igrp/framework-next-types`' `check:contract`, so it cannot drift from it.

This was the template's only direct import of
`@igrp/platform-access-management-client-ts` under `src/`. The dependency stays
in `package.json`: remove it yourself only if your own code no longer uses it.
