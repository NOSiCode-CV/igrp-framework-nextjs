# 49 — Framework `0.2.0-beta.2`

## What changed

| Dependency | From | To |
| --- | --- | --- |
| `@igrp/framework-next` | `0.2.0-beta.1` | `0.2.0-beta.2` |
| `@igrp/framework-next-ui` | `0.2.0-beta.1` | `0.2.0-beta.2` |
| `@igrp/igrp-framework-react-design-system` | `0.2.0-beta.1` | `0.2.0-beta.2` |
| `@igrp/platform-access-management-client-ts` | `0.2.0-beta.17` | removed (provided by `@igrp/framework-next`) |

`@igrp/framework-next-auth` and `@igrp/framework-next-types` stay at `0.2.0-beta.1`.
No template source files change.

## Why

The design system restores props that were removed after `0.1.x` as
`@deprecated` shims, so apps written against `0.1.0-beta.126` compile again:
`IGRPRadioGroup` `size` / `gridSize` / `variant="outline" | "soft"`,
`IGRPAvatar` `size`, `IGRPButton` `iconSize`, `IGRPInputColor` `showHexValue`,
`IGRPDataTableCellDate` `dateFormat`, `IGRPModalDialogContent`
`showCloseButtonClassName`, `IGRPModalDialogDescription` `name`, and
`IGRPStandaloneList`. They will be removed in the next release — move to the
replacements named in each prop's `@deprecated` note.

Two behaviour changes to check:

- `IGRPDataTableCellDate` and `IGRPDataTableCellAmount` now default `language`
  to the `IGRPI18nProvider` locale (`pt-PT`) instead of `en-US`. Pass
  `language="en-US"` to keep the previous output.
- The `IGRPGridSize` type and the `igrpGridSizeClasses` export were removed.
  Replace any import with your own grid classes.

`next-ui` and `next` only pick up the new design-system version.

## After applying

```bash
pnpm install
```

If your own code imports `@igrp/platform-access-management-client-ts`
directly, add it back to `dependencies` after applying.
