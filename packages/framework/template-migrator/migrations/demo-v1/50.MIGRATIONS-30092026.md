# 50 — Silent SSO on `/login`

## What changed

| File | Change |
| --- | --- |
| `src/lib/silent-sso.ts` | new — decision rule, loop-guard cookie, callbackUrl recovery |
| `src/app/(auth)/login/silent-sign-in.tsx` | new — runs `signIn(..., { prompt: "none" })` behind an "Aguarde..." loading screen |
| `src/app/(auth)/login/page.tsx` | tries a silent sign-in before rendering the form |
| `src/app/(auth)/login/logout-completion.tsx` | suppresses the silent attempt right after a logout |
| `src/lib/auth-instance.ts` | `pages.signIn` now carries the basePath |

No dependency changes.

`pages.signIn` fixes a separate, older defect that the silent path depends on.
NextAuth uses that value verbatim as a redirect, so `"/login"` sent every
NextAuth error (`?error=Callback`, `?error=OAuthSignin`, …) to `<origin>/login`
— a 404 for any app with `NEXT_PUBLIC_BASE_PATH`.

## Why

Apps sharing one IdP each keep their own session cookie, so moving from one
app to another landed on `/login` and needed a click — even though the IdP
session was still alive and the click returned instantly.

`/login` now first asks the IdP for a code with `prompt=none`. With a live IdP
session the user goes straight into the app. Without one, the IdP answers
`login_required`, NextAuth returns to `/login?error=Callback`, and the form
is shown as before. A short-lived cookie (`igrp.silent-sso<basePath suffix>`,
60 s) guards against a retry loop and keeps the original `callbackUrl`.

Only the OIDC-managed provider (`igrp-auth`) tries silently. Preview mode,
`AUTH_PROVIDER=none` and the deferred-logout path are unchanged, and a user who
has just signed out always sees the form.

## Requirements

The IdP must honour `prompt=none` by redirecting to the `redirect_uri` with
`error=login_required`. If it shows its own login page instead, users without
an IdP session see the IdP's form rather than the app's button — sign-in still
works.

## After applying

If you customised `login/page.tsx` or `logout-completion.tsx`, re-apply your
changes on top of the new versions.
