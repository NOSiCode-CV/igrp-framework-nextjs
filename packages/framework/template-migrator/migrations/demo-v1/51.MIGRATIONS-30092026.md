# 51 — Framework `0.2.0-beta.3`

## What changed

| Dependency | From | To |
| --- | --- | --- |
| `@igrp/framework-next` | `0.2.0-beta.2` | `0.2.0-beta.3` |
| `@igrp/framework-next-auth` | `0.2.0-beta.1` | `0.2.0-beta.2` |
| `@igrp/framework-next-types` | `0.2.0-beta.1` | `0.2.0-beta.2` |
| `@igrp/framework-next-ui` | `0.2.0-beta.2` | `0.2.0-beta.3` |
| `@igrp/igrp-framework-react-design-system` | `0.2.0-beta.2` | `0.2.0-beta.3` |

No template source files change.

## Why

- `next-auth`: the post-login redirect no longer drops the app's `basePath`.
  Relative callback URLs are no longer double-prefixed, and a same-origin
  absolute URL outside the basePath now lands on the app home.
- Design system: `IGRPTabs` / `Tabs` style the selected tab in every variant,
  show the `underline` indicator, use the right foreground for `pills`, and
  report the correct orientation when vertical. The scroll arrows no longer
  remount while scrolling and respect reduced motion. `IGRPTabItem` gains
  `ariaLabel` and `keepMounted`, and its `className` is now applied.

`next-types`, `next-ui` and `next` only pick up the versions above.
