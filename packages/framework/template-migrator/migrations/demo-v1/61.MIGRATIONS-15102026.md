## Why

The framework versions are the release that ships the i18n runtime (migration 58) and organization branding (migration 60); see each package's CHANGELOG.

The three app dependencies moved with the framework's dependency refresh. They
are patch or minor releases with no API changes the template relies on; this keeps migrated apps on the same versions a fresh template ships with.
