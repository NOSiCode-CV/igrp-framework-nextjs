# 70 — Framework release 0.2.0-beta.12

## What changed

| Dependency | From | To |
| --- | --- | --- |
| `@igrp/framework-next` | `0.2.0-beta.11` | `0.2.0-beta.12` |
| `@igrp/framework-next-ui` | `0.2.0-beta.11` | `0.2.0-beta.12` |
| `@igrp/igrp-framework-react-design-system` | `0.2.0-beta.7` | `0.2.0-beta.8` |

`@igrp/framework-next-i18n` (`0.2.0-beta.3`), `@igrp/framework-next-auth` and
`@igrp/framework-next-types` (`0.2.0-beta.8`) are unchanged.

## Why

On Linux the design system and next-ui builds put their CSS at
`dist/src/tokens.css` instead of `dist/tokens.css`, so the `./tokens` export
resolved to nothing and Tailwind failed to load it. Windows builds were
unaffected. No template files change.

## After migrating

Run `pnpm install`.
