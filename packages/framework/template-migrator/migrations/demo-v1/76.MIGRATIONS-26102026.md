# 76 — framework-next 0.2.0-beta.15

## What changed

| Dependency | From | To |
| --- | --- | --- |
| `@igrp/framework-next` | `0.2.0-beta.14` | `0.2.0-beta.15` |
| `@igrp/framework-next-auth` | `0.2.0-beta.8` | `0.2.0-beta.9` |
| `@igrp/framework-next-types` | `0.2.0-beta.8` | `0.2.0-beta.9` |
| `@igrp/framework-next-ui` | `0.2.0-beta.12` | `0.2.0-beta.13` |
| `@igrp/igrp-framework-react-design-system` | `0.2.0-beta.8` | `0.2.0-beta.9` |

## Why

- NextAuth sessions default to `maxAge` 8 h (was 30 days), matching Access Management's absolute session limit.
- `IGRPRootLayout` checks the Access Management session when a tab regains focus (at most once a minute). A session that ended elsewhere (logout in another app, admin kill) goes to `/login?reason=session_ended`, which migration 75 adds.
- The Access Management client moves to `0.2.0-beta.21` (a dependency of `@igrp/framework-next`). The `rotateSession` warning is gone; `closeSession` still warns.

Apply migration 75 first: the focus check redirects to the `session_ended` page it adds.

## After migrating

Run `pnpm install`. An app that also pins `@igrp/platform-access-management-client-ts` itself should move it to `0.2.0-beta.21`.
