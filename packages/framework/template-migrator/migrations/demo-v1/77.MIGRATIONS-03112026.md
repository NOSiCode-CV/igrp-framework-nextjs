# 77 — framework-next 0.2.0-beta.16

## What changed

| Dependency | From | To |
| --- | --- | --- |
| `@igrp/framework-next` | `0.2.0-beta.15` | `0.2.0-beta.16` |
| `@igrp/framework-next-ui` | `0.2.0-beta.13` | `0.2.0-beta.14` |
| `@igrp/igrp-framework-react-design-system` | `0.2.0-beta.9` | `0.2.0-beta.10` |

## Why

- Accordion and `IGRPFormList` rows no longer clip content that appears after the row opens (upload results, validation messages, conditional fields).
- Open/close animations work again on dialog, sheet, drawer, popover, hover-card, select, menu and accordion. `tokens.css` maps the `data-open:` / `data-closed:` variants to Radix's `data-state`.
- Deprecated Headline `roleColor` and `color` props no longer reach the DOM in older generated pages.

`framework-next` and `framework-next-ui` only move to pick up the new design system.

## After migrating

Run `pnpm install`. The app must import `@igrp/igrp-framework-react-design-system/tokens` in `globals.css` for the animations to apply. An app that added `[&_[data-slot=accordion-content]>div]:h-auto` as a workaround can drop it.
