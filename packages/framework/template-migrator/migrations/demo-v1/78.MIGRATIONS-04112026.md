The non-IGRP rows catch apps up with the template's own dependency update.

## Why

- New components: `IGRPServerDataTable` (server-paginated table), `IGRPButtonLink` (link button with a loading spinner and tooltip), `IGRPLookupField`, `IGRPMultiStepForm`, `IGRPTooltip`.
- `IGRPAccordion` items take `action`, `count`, badges and an empty state, and `type="multiple"` keeps several items open.
- `IGRPDataTable` gets `getRowId` (expanded rows follow the record, not the row index) and a `layout` prop. `IGRPDataTableButtonLink` with `href` and `disabled` no longer navigates.
- `IGRPTextarea` gets a character counter. `IGRPForm` accepts `children` as a function of the form.

`framework-next` and `framework-next-ui` only move to pick up the new design system.

## Behaviour changes to check

- **Data-table cells** truncate below `lg` and wrap from `lg`, where before they always truncated. The generated `actions` column drops its inline width and shrinks to fit. Mark custom action columns with `meta.isActionsColumn` to keep them on one line.
- **Row-action tooltips** wrap the button in an `inline-flex` span; `aria-describedby` and `data-state` now sit on that span. Update tests or selectors that read them from the button.
- **`IGRPTextarea` with `maxLength`** truncates values set through `setValue` or `reset` and marks the field dirty. Pass `enforceMaxLength={false}` for the old behaviour.
- **Exported `StepperIndicator` / `StepperSeparator`** use the new step tokens: completed steps turn the success colour.
- The design system's `next` peer dependency is now `^15.3.0`.

## After migrating

Run `pnpm install`. Apps on `next` below 15.3 must upgrade it.
