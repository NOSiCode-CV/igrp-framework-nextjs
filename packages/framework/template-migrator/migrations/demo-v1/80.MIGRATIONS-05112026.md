# 80 — framework-next 0.2.0-beta.19

## What changed

| Dependency | From | To |
| --- | --- | --- |
| `@igrp/framework-next` | `0.2.0-beta.18` | `0.2.0-beta.19` |
| `@igrp/framework-next-ui` | `0.2.0-beta.16` | `0.2.0-beta.17` |
| `@igrp/igrp-framework-react-design-system` | `0.2.0-beta.12` | `0.2.0-beta.13` |

## Why

- `IGRPDatePickerMultiple` clears a field that has a default value. Before, the clear button wrote `undefined`, react-hook-form treated the field as unset, and the default dates came back.

`framework-next` and `framework-next-ui` only move to pick up the new design system.

## Behaviour changes to check

- **`IGRPDatePickerMultiple`** in a form now writes `null` when cleared. A schema that does not accept `null` fails validation on a cleared field: use `z.array(z.date()).nullable()`.

## After migrating

Run `pnpm install`.
