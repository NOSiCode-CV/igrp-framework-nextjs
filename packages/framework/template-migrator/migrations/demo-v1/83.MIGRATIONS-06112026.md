# 83 — Ship the template docs

## What changed

Upgraded apps now get every guide in `docs/`. Until now only `docs/I18N.md`
was shipped by a migration; the other ten reached new apps through the
template zip and never reached upgraded ones:

`ACCESS_MANAGEMENT.md`, `ARCHITECTURE.md`, `AUTHENTICATION.md`,
`DESIGN_SYSTEM.md`, `DOCKER-RUN.md`, `ENVIRONMENT.md`, `HEADER_SLOTS.md`,
`MIGRATION_GUIDE.md`, `PERMISSIONS.md`, `TOKENS.md`.

## Why

The drift gate exempted `docs/`, so nothing forced a migration when a guide
was added or edited. That exemption is gone: a docs change now fails
`check:drift` until a migration ships it.

## After migrating

Nothing to run. Each file is replaced in full: if you edited one of these
guides in your app, compare it with your version control and re-apply your
changes.
