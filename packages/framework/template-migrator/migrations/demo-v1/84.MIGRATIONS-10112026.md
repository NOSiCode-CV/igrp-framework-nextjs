# 84 — Inline scripts carry a per-request CSP nonce

## What changed

| File | Change |
| --- | --- |
| `src/middleware.ts` | Creates a nonce for every request that reaches a page, forwards it as the `x-nonce` request header and adds `'nonce-…'` to `script-src` in the `Content-Security-Policy-Report-Only` header. In production the policy is also set on the request, which is where Next.js reads the nonce for its own inline scripts. |
| `src/app/layout.tsx` | Reads `x-nonce` and passes it to `IGRPRootLayout` as `nonce`, which hands it to next-themes' theme boot script. |

| Dependency | From | To |
| --- | --- | --- |
| `@igrp/framework-next` | `0.2.0-beta.20` | `0.2.0-beta.22` |
| `@igrp/framework-next-ui` | `0.2.0-beta.18` | `0.2.0-beta.20` |
| `@igrp/igrp-framework-react-design-system` | `0.2.0-beta.14` | `0.2.0-beta.15` |

## Why

`script-src` does not allow `'unsafe-inline'`, so every page logged a CSP violation for the theme boot script and for Next.js' own inline scripts. With the nonce in place the report-only policy is clean, and an app can switch it to an enforcing `Content-Security-Policy` without breaking the theme.

The design-system bump fixes `IGRPStepperProcess` throwing "Tooltip must be used within TooltipProvider" when the app-level provider came from another copy of the design system.

## Behaviour changes to check

- The policy is still report-only and still sent in production only. Nothing is blocked.
- Every page response now has its own policy string, because the nonce changes per request. A cache or proxy that stores HTML responses must not serve one user's page with another's nonce. Pages in this template are already `force-dynamic`.

## After migrating

Nothing to do. If you changed either file, merge by hand:

- `middleware.ts`: in the pass-through branch, generate `btoa(crypto.randomUUID())`, set it as the `x-nonce` request header and put `'nonce-<value>'` in `script-src`. In production, set the policy on the request headers as well as on the response.
- `app/layout.tsx`: `const nonce = (await headers()).get("x-nonce") ?? undefined;` and pass `nonce={nonce}` to `IGRPRootLayout`.
