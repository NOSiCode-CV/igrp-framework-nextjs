# 86 — API routes with a file extension go through the auth check

## What changed

| File | Change |
| --- | --- |
| `src/middleware.ts` | `isPublicPath` no longer treats an `/api/*` path as a static asset. Migration 85 still let `/api/reports/2026.pdf` or `/api/export/data.json` through without a session, because `json`, `pdf`, `txt` and `xml` are on the asset list. |
| `src/app/api/csp-report/route.ts` | Logs the report body as a quoted JSON string, so a body with newlines cannot add fake lines to the server log. |

## Behaviour changes to check

- An unauthenticated request to an `/api/*` route whose last segment has a file extension now gets the same treatment as any other protected route.

## After migrating

Nothing to do. If you changed either file, merge by hand:

- `middleware.ts`: in `isPublicPath`, return `!pathname.startsWith("/api/") && STATIC_ASSET_RE.test(...)`.
- `csp-report/route.ts`: log `JSON.stringify(await request.text())`.
