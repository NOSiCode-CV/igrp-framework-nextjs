# 94 — Tests for the middleware and the login/logout flow

## What changed

| File | Change |
| --- | --- |
| `src/__tests__/middleware.test.ts` | New. Which paths skip the token check (a dotted page route and an asset-looking API route do not), the `callbackUrl` guard, the `logout_pending` backstop, the security headers and CSP in production, and the stale-cookie sweep under a basePath. |
| `src/lib/__tests__/auth-markers.test.ts` | New. `shouldAttemptSilentSso`, `silentSsoCallbackUrl`, and the cookie attributes of the silent-SSO and logout-pending markers. |
| `src/lib/__tests__/dal.test.ts` | New. `verifySession` with bypass on and off and the sanitised login redirect; `getAuthenticatedUser` never returns tokens. |
| `src/lib/__tests__/session-store.test.ts` | New. The Redis session store against an in-memory client: TTLs, reconnect after a failed connect, the 2 s timeout, and the refresh lock. |
| `src/actions/igrp/__tests__/auth.test.ts` | New. `markHostLogout` and `getLogoutUrl`. |

## Why

Only the bypass paths had tests. The middleware, the session check and the logout flow decide who gets into the app, and an app built from this template inherits them unchanged.

## Behaviour changes to check

None. These files only add tests. If you changed `src/middleware.ts`, `src/lib/dal.ts`, `src/lib/session-store.ts`, `src/lib/silent-sso.ts`, `src/lib/logout-pending.ts` or `src/actions/igrp/auth.ts`, some cases may fail: they describe the template's behaviour. Update or delete the cases that no longer match yours.

Run `pnpm test`.
