## Behaviour changes to check

- **Deprecated layout props.** `IGRPLayoutFull` takes `header`, `sidebar`, `toaster` and `contentClassName`; `showSidebar`, `headerSlots`, `breadcrumbs` and `breadcrumbRouteLabels` still work but are deprecated, and are ignored (with a development warning) when passed together with `header` or `sidebar`.
- **Client session.** `session.idToken` is no longer sent to the browser. Logout reads it on the server. If client code read it, move that code to the server.
- **Loading buttons.** `IGRPButton` with `loading` stays focusable and uses `aria-disabled`; clicks and form submits are cancelled while it loads.
- **Multipart forms.** `convertValuesToFormData` sends a cleared field (`null`) and an empty array as `""` instead of leaving the key out, so the server sees the clear.
- **Preview mode.** Framework server actions return `{ ok: false, code: 'AUTH_BYPASSED' }` when no Access Management credentials are configured.
- **lucide-react.** Both `^0.577.0` and `^1.0.0` are accepted.
