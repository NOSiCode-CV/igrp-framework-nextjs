# 96 — Logout waits long enough for the IdP

## What changed

| File | Change |
| --- | --- |
| `src/app/(auth)/logout/page.tsx` | `LOOKUP_TIMEOUT_MS` goes from 3000 to 5000. |

## Why

The page gave up on the end-session URL after 3 s, but the server waits up to 4 s for the IdP's discovery document. A discovery that took between 3 and 4 s answered after the page had already given up, so logout was local-only and the IdP session stayed open.

## Behaviour changes to check

Against an IdP that does not answer at all, logout takes up to 5 s instead of 3 s before it falls back to a local sign-out. If you changed `LOOKUP_TIMEOUT_MS`, keep it above 4000 and below `FALLBACK_TIMEOUT_MS` (8000).
