# 97 — One entry point for the access-client credentials

## What changed

| File | Change |
| --- | --- |
| `src/lib/auth.ts` | `serverSession()` and `getSession()` call `igrpEnsureAccessClientConfig({ token })` instead of `igrpSetAccessClientConfig({ token, baseUrl })`. |

## Why

`@igrp/framework-next` now fills the per-request Access Management store through one function, `igrpEnsureAccessClientConfig(seed?)`, and its doc comment holds the ordering rules that used to be spread over four files. The base URL defaults to `IGRP_ACCESS_MANAGEMENT_API`, so the template no longer reads it.

## Behaviour changes to check

None. A session without an `accessToken` now seeds an empty token in `serverSession()` too, as `getSession()` already did. `igrpSetAccessClientConfig` is still exported; code of your own that calls it keeps working.

## After migrating

Needs `@igrp/framework-next` `0.2.0-beta.25` or later.
